# Publicação obrigatória do aplicativo

- Toda atualização concluída no Estoque Bolsas Baby deve ser publicada no GitHub.
- Antes de publicar, incremente a versão do aplicativo, valide o código, gere o executável e confirme que ele inicia corretamente.
- A publicação deve incluir o código versionado no repositório e uma GitHub Release com o executável do Windows anexado.
- Instale localmente o mesmo executável publicado e deixe o aplicativo aberto para conferência.
- Não considere uma atualização concluída enquanto o envio e a release não estiverem confirmados no GitHub.
